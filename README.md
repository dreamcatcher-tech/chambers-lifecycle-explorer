# Chambers Atlas

A polished, playable explorer for the Chambers lifecycle sequence reference.

**Live site:** <https://dreamcatcher-tech.github.io/chambers-lifecycle-explorer/>

## What it provides

- **Trace** — custom sequence lanes with play/pause, step, scrub, actor focus, call-type filtering, zoom, keyboard shortcuts, touch gestures, and deep links.
- **Map** — an actor relationship graph with directed, frequency-weighted connections and call drill-down.
- **Functions** — the complete function table, including all I3 functions, the four critical conventional host calls, and defined functions not pictured in a diagram.
- **Exact provenance** — every generated call resolves to the copied function table and the snapshot is bound to its Fundamentals source commit and SHA-256.
- **Source jump** — the snapshot card and footer open the exact private GitHub source document in a new page for viewers with repository access.
- **No runtime dependencies** — the published artifact is plain HTML, CSS, JavaScript, and generated data. No CDN or Mermaid runtime is needed.

## Source and update model

The authoritative source is the private Fundamentals checkout at:

```text
dreamcatcher-tech/fundamentals
docs/chambers-lifecycle-sequences.md
```

This public repository contains an intentional committed snapshot. Because the source repository is private, the initial publishing path is deliberately simple and fail-closed: copy only a **committed** source file, regenerate, validate, and push this repository.

```bash
git -C ../fundamentals fetch --all --prune
git -C ../fundamentals pull --ff-only
python3 scripts/sync_source.py ../fundamentals
python3 -m unittest discover -s tests -v
python3 scripts/build_data.py --check --print-summary
python3 scripts/validate_site.py
git add source site/data.js
git commit -m "docs: sync lifecycle sequence source"
git push
```

`sync_source.py` refuses to copy an uncommitted lifecycle document. A push to `main` validates and republishes GitHub Pages.

## Local preview

```bash
python3 -m http.server 8008 --directory site
# open http://127.0.0.1:8008/
```

Useful deep-link parameters are generated by the UI:

```text
?diagram=selection-rollback&call=selection-rollback-call-5
?diagram=candidate-verification&view=map
?view=functions&function=chambers%3A%3Aprocess%3A%3Apropose
```

## Architecture

```text
source/chambers-lifecycle-sequences.md
                │
                ▼
       scripts/build_data.py
       ├─ parses function table
       ├─ parses every sequence arrow
       ├─ preserves branches and notes
       └─ rejects unknown function labels
                │
                ▼
           site/data.js
                │
       ┌────────┼────────┐
       ▼        ▼        ▼
     Trace     Map    Functions
```

The parser treats names containing `::` according to the source function table, not by visual guesswork. `wake_engine`, `activate_chamber`, `stop_chamber`, and `deliver_final_reply` remain explicitly classified as external conventional calls.
